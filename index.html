A closer look at your text.

Upload a UTF-8 text file or type in the workspace. Statistics update instantly. Export a report whenever you’re ready.

Words are sequences of letters or digits with optional internal apostrophes. Hyphens split words. Frequencies ignore case. Sentence counts split at periods, question marks, and exclamation marks, so abbreviations and decimals can affect the estimate.

Reading time assumes 200 words per minute. Lines include blank lines, but a trailing newline adds no extra line. Reports include all word frequencies, even when the chart hides common words.

Document extraction reads text, not visual layout. Spreadsheet values are analyzed as displayed text. Image OCR is English by default and can make recognition errors. PDF scans without a text layer need conversion to images for OCR.

Bring your documents.

Extract text from these formats, then run the same live analysis.

  • Documents: PDF (text layer), DOCX, ODT
  • Spreadsheets: XLSX, XLS, ODS, CSV, TSV
  • Presentations: PPTX, ODP
  • Images (English OCR): PNG, JPEG, WebP, BMP
  • Text & code: TXT, Markdown, JSON, HTML, XML, YAML, logs, Python, JavaScript, Java, C/C++, CSS, SQL, and other UTF-8 plain text files

20 MB per file; 2 million extracted characters. Password-protected files, old DOC/PPT binaries, archives, audio, video and executables are unsupported. Scanned PDFs need image conversion first. OCR downloads an English recognition model on first use; text is processed locally.
