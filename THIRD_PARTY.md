- Tesseract.js 5.1.1 — Apache-2.0 — https://github.com/naptha/tesseract.js

Image OCR downloads its worker, WebAssembly engine and English model on first use.
Google sign-in uses the official Google Identity Services client. A Google OAuth
web client ID and authorized JavaScript origin are required. No client secret is
used. Access tokens are held in memory; no server account or cloud document store
is created. The existing hosting access policy remains separate from this profile.
